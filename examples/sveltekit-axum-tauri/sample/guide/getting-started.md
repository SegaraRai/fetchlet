# Getting started

## Start

In a browser:

```bash
mdw serve ~/notes --open
```

In a desktop window:

```bash
mdw desktop ~/notes
```

## Configuration

`config.json` sets the budgets.

```json
{
  "note_bytes": 1048576,
  "workspace_notes": 10000
}
```

The documentation moved to https://fetchlet.roundtrip.dev/docs. The `fetchlet` package ships every page as Markdown in `docs/`, with an index in `docs/llms.txt`, so that coding agents read the documentation of the installed version. It also ships the `setup-fetchlet` and `fetchlet` skills for coding agents in `skills/`, and `AGENTS_TEMPLATE.md`, a section for a project's instruction file. The crate READMEs summarize each crate and link to its page on the website.

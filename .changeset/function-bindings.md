`HostServices::functions(name, Functions)` binds Rust functions that JavaScript calls as the methods of `fetchlet.env.NAME`, a frozen object of exactly those methods. `Functions::method` adds an async method, which returns a Promise whose future is polled with the invocation's host operations, under its deadline, and dropped when it ends; `sync_method` adds one that returns at once. `FunctionRequest::args` deserializes the arguments with serde, and arguments it cannot read throw a `TypeError` naming the method; `FunctionError::new(message).code(code)` arrives as an `Error` with that message and `code`, a fetchlet `Error` as a host error, and a panic fails the call with `PANICKED`. An `ArrayBuffer` or view in the arguments crosses as its bytes, which `args` reads into `Vec<u8>` or `Bytes`. A method returns any type that converts into `FunctionResponse`, such as a JSON value, `Bytes` or `Vec<u8>`; `FunctionResponse::bytes_at` places byte arrays, which JavaScript receives as `Uint8Array`s, and `channel_at` lends channels, which belong to the invocation, at JSON Pointer positions of the result. `request.context()` gives the invocation's trusted `Context`. The new `Limits::function_calls` bounds the calls per invocation, and `bridge_message_bytes` bounds each result.

# fetchlet website

[fetchlet](https://fetchlet.roundtrip.dev/) runs the server side of JavaScript
web frameworks inside a Rust application, on QuickJS, Boa or V8.

This package contains fetchlet's private Astro website: the landing page and
the Nimbus documentation under `/docs`. Its build also writes the Markdown
pages that the `fetchlet` npm package ships in `docs/`.

See [Development](DEVELOPMENT.md) for local tasks, the documentation layout,
and deployment.
